# ⏱ Countdown Timer Web App

A simple and stylish countdown timer built using **HTML**, **CSS**, and **JavaScript**. Users can input a time in seconds and control the timer using Start, Stop, and Reset buttons.

## 📂 Project Structure

```
├── index.html    # The main HTML page
├── style.css     # Styling for the timer
└── app.js        # JavaScript logic for countdown functionality
```

## 🚀 Features

- Input time in seconds
- Start and stop the countdown
- Reset the timer and input field
- Stylish circular timer display
- Responsive and centered UI

## 🛠 How to Use

1. Clone the repository or download the ZIP:
   ```bash
   git clone https://github.com/your-username/countdown-timer.git
   ```
2. Open `index.html` in your browser.
3. Enter time in seconds, and click **Start**.
4. Use **Stop** to pause or **Reset** to clear the timer.

## 📜 Code Highlights

- `setInterval` used for time tracking.
- Input validation for non-zero time.
- Dynamic DOM manipulation to update the timer display.
